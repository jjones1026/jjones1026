## 🛠️ Featured Projects

### 🌍 GIS Solutions

- **Port Orange Debris Management System (PODMS)**  
  A full-stack GIS dashboard for visualizing debris collection operations. Combines ArcGIS, Python automation, Word reports, and email integration to streamline emergency response logistics.

  A spatial solution for tracking invasive species, fire break lines, and forestry health. Features include field data collection forms, dynamic dashboards, and multi-layer web maps for mitigation planning.
